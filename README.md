# Express & MongoDB Atlas CRUD App

Проєкт реалізує взаємодію сервера Node.js/Express із базою даних MongoDB Atlas з підтримкою операцій CRUD:
- Створення: `insertOne`, `insertMany`
- Читання: `find` з проєкцією
- Оновлення: `updateOne`, `updateMany`, `replaceOne`
- Видалення: `deleteOne`, `deleteMany`
